# Zhen Mei Hair Salon

Website for Zhen Mei Hair Salon in San Francisco's Chinatown.

## Run locally

Requires Node.js 22.12 or newer and npm.

```sh
npm ci
npm run dev
```

## Build and deploy

```sh
npm run build
```

The finished static website is in `dist/`. Upload that folder to any static web host or copy its contents to a web server. The build uses relative asset paths and does not require a server-side runtime, environment variables, or rewrite rules.
